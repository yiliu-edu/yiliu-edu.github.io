## How to run a skill
1. Open a new chat in Claude.
2. Paste the full text of one skill file (for example `skills/02-impact-check.md`).
3. Replace the `{{...}}` placeholders with real inputs: the release notes, one asset from `content/library.json`, the feature tag list.
4. Copy the output into the log below, then check it against `skills/04-review-rubric.md`.
5. When the output is wrong, change the skill, bump its version, and run it again. Note what you changed and why.
