# Station check card: before you release

Read every number in pairs.

1. Product name and size match the work order
2. REF digits match
3. LOT digits match, and match the UDI (10)
4. Use-by: year, month and day match, and match the UDI (17)
5. Sterility symbol present and correct for the product
6. Quantity matches

Any mismatch: hold, segregate, record, notify. Leave the cause to the investigation.

A good record says who, when, which work order and lot, what didn’t match, what happened to the product, and who was told.
