# LMS packages

| Package | Format | Built from | What it reports |
|---|---|---|---|
| right-first-time-scorm2004.zip | SCORM 2004 4th Edition, one SCO | Right First Time, slide-based course | Completion, pass/fail (pass mark 80%), score, one interaction per label and for the deviation record, bookmark to resume |
| ai-in-your-course-canvas.imscc | IMS Common Cartridge 1.1 | AI in Your Course faculty workshop | Four modules with pages, the explainer video, a discussion, a 3-question quiz and a link to the self-paced kit |

## Status
- SCORM package: tested with a mock SCORM 2004 API (completion, score, success status, interactions, bookmark). Next step: upload to SCORM Cloud and record the registration report. See `scorm-cloud-guide.md`.
- Canvas package: built to the Common Cartridge 1.1 format. Next step: import into a Canvas sandbox course and check modules, the quiz and the discussion. See `canvas-import-guide.md`.
