# Import the course into Canvas

Instructure no longer registers new Free-for-Teacher accounts, so use a sandbox course at your institution (many universities give staff and students a sandbox on request), or ask a Canvas admin for one.

1. Open the empty sandbox course → Settings → Import Course Content.
2. Content Type: Common Cartridge 1.x Package. Choose `ai-in-your-course-canvas.imscc`, select All content, and Import.
3. Check Modules: four modules should appear, each with its items in order.
4. Open the Module 1 page and play the video. Open the quiz in Module 3 and preview it.
5. Set up what the cartridge format can’t carry, and screenshot each step:
   - Module requirements (view each page, submit the quiz) and prerequisites so modules unlock in order
   - Quiz settings: unlimited attempts, show correct answers after the last attempt
   - A rubric on the discussion (post one assignment and its level; reply to one colleague)
   - Course home page set to Modules
6. Use Student View to walk through the course once, then check New Analytics or the quiz statistics.

What to say in an interview: “I built the course as a Common Cartridge, imported it into Canvas, and set up module requirements, quiz settings and a discussion rubric.”
