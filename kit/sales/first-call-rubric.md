# First live call rubric (manager, Day 10)

Used by the manager who shadows a new seller’s first live discovery call. It rates the same call stages the seller practiced in the sprint, so practice, assessment and on-the-job feedback use one language. Results feed Kirkpatrick Level 3 (behavior).

Rate each stage: 1 = not seen, 2 = partly, 3 = clearly done.

| Stage | What “clearly done” looks like | Rating |
|---|---|---|
| Open | Thanks the client, asks about their goals before mentioning any product | |
| Discover | Asks how customers find the business today and what happens after they call or click | |
| Recommend | Recommends a small, measurable starting campaign tied to the client’s stated goal | |
| Concern | Acknowledges the concern, asks about it, and reduces risk with a clear measure (no discount as the first answer) | |
| Next step | Agrees on a specific next step with a date and who does what | |
| CRM note | Saves a note that includes the goal, the recommendation, the success metric and the next step | |

Ready to run calls alone: 3 on Next step and CRM note, and at least 2 on every other stage.

## Debrief (15 minutes, right after the call)
1. Seller first: which stage went best, and which would you redo?
2. Manager: one strength and one stage to practice, using the rubric wording.
3. Agree on one practice: replay that stage in the AI client role-play before the next call.
